# Multimodal-Process-Reward-Model-R-PRM-for-Geometric-Reasoning
Addressing the critical challenges of visual topological hallucinations, deductive leaps, fallacious pseudo-proofs, and lack of interpretability in Large Vision-Language Models (VLMs) during complex geometric reasoning tasks, this project develops and delivers an multimodal process reward model: Qwen3-VL-8B-RPRM-v2.
